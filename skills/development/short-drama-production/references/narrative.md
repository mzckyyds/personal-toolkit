# 视频叙事原则

## 降低理解成本，提高信息密度，让观众始终期待下一秒

- **开头抓人**：第一个镜头呈现异常、冲突或悬念，禁止冗长铺垫。
- **信息密集**：后续每个镜头争取产生一次有效信息变化，避免重复与冗余。
- **悬念驱动**：持续制造并解决小悬念，推动观众期待后续发展。
- **冲突升级**：情节逐步升级，避免平铺直叙，最终形成高潮或反转。
- **视觉优先**：优先通过画面与行动传递信息，减少解释性的对白和旁白。
- **节奏自然**：依据叙事需要切镜，不为追求快节奏而机械切换。
- **结尾有力**：以反转、讽刺或情绪释放收束，自然揭示核心规律。
- **时长精简**：以有效叙事决定时长，删除不推动情节的内容。

## 五阶段结构：冲突 → 规则 → 升级 → 高潮 → 余韵

以 60 秒为例：

1. **冲突（0–5秒）**：直接呈现异常、矛盾或悬念，迅速吸引注意。
2. **规则（5–15秒）**：交代角色处境、目标及故事规则，建立冲突逻辑。
3. **升级（15–40秒）**：通过因果关系推动冲突逐步加剧，避免机械重复。
4. **高潮（40–55秒）**：将冲突推向极致，以反转、荒诞结果或情绪爆发形成高潮。
5. **余韵（55–60秒）**：通过对白、旁白、动作或画面收束故事，自然呼应主题。

**注意事项：**

- 阶段与时间仅供参考，可根据题材、时长和叙事需要灵活调整，不强求反转。
- 阶段不等于场景或镜头，允许合并，不机械切分。
- 压缩无效铺垫，提高叙事密度，而非盲目加快剪辑。
- 优先通过画面和行动讲述故事，以因果递进推动情节，避免说教式总结。
